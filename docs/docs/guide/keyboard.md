# Keyboard shortcuts

| Shortcut | Action |
| -------- | ------ |
| `Space` | Start or pause the timer (when no sheet is open) |
| `⌘,` | Open Settings (macOS) |
| `Esc` | Close Settings, Tasks, Sessions, or a confirmation dialog |

When a **confirm** dialog is open (e.g. switching mode mid-timer), keyboard shortcuts for the main timer are ignored until you dismiss it.
